# ProjectKart website (HTML, CSS and JavaScript)

A responsive one-page website built from the layout direction in `ProjectKart_Website_Design.pdf`.

## Files
- `index.html` — page sections and form markup
- `styles.css` — responsive design, layout and visual styling
- `script.js` — mobile navigation, service selection, current year, date validation and WhatsApp enquiry form

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Safari or Firefox.
3. For a local server (optional), run `python -m http.server 8000` in this folder and open `http://localhost:8000`.

## How the order form works
The form validates required fields, then opens WhatsApp with a prefilled enquiry message. The visitor must review and send the message in WhatsApp. This static website does not store form submissions or process payments.
